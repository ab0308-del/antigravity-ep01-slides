CORE CONCEPT

聊天 vs 動手：AI Agent 差在哪？

💬 生成式 AI（聊天）

產出文字／圖片，要你自己複製貼上。
不能動你電腦上的檔案。

🛠️ AI Agent（動手）

真的會做事：開檔、改檔、整理、上網。
可以處理你的本地端檔案。

一句話：請一個一個月 600 多塊、會動手的數位助理。

怎麼判斷它是不是 Agent？

看它能不能動你的
「本地端檔案」

能 → 是 Agent　｜　不能 → 只是聊天

  • 已註冊 Padlet 帳號

PART 1

下載軟體與環境佈置

下載 → 設定 → 起手式

PART 1 — (a)

下載 AntiGravity 並登入

  1. 1
    到 AntiGravity 官方網站下載安裝（Windows／Mac）。講師現場提供下載連結
  2. 2
    用 Google 帳號登入。
  3. 3
    有訂閱 Google 方案者，享 3 倍用量，比較不會跑一跑就沒額度。

PART 1 — (b)

第一次環境佈置：三個關鍵設定

  1. 1
    先看額度：左下 Settings → Model，確認 5 小時／週用量。
  2. 2
    打開 Turbo Mode（自動略過部分逐次確認）。
  3. 3
    把 Artifact Review 設成 Always Proceed。
  4. 4
    在 Terminal Command 允許 npm、python。
選單名稱可能因版本略有不同，以現場畫面為準。

PART 1 — (c)

起手式：一定要有「工作資料夾」

  1. 1
    新開專案 → Add Folder，選一個本機資料夾（⚠️ 別放雲端硬碟同步夾）。
  2. 2
    對它說：「這是新專案，幫我初始化」→ 它會建立專案藍圖檔。
  3. 3
    心法：Agent 會動你的真實檔案 → 永遠在資料夾裡工作。

ONE-CLICK SETUP

課程懶人包：貼一行，自動設定好

📦 課程懶人包 repo

github.com/ab0308-del/antigravity-starter-kit
  1. 1
    下載 / clone 到本機：# 終端機
    git clone https://github.com/ab0308-del/antigravity-starter-kit.git

PART 2

嘗試操作：讓 AI 整理桌面

第一次成功，就是這一刻

HANDS-ON

整理練習：把亂資料夾變整齊

  1. 1
    打開懶人包裡的 練習素材／整理練習／（18 個雜亂檔）。
  2. 2
    把資料夾 Add Folder 進 AntiGravity。
  3. 3
    下這句指令：幫我把這個資料夾的檔案，依類型分到子資料夾
    （圖片／文件／簡報／表格／PDF／壓縮檔／其他），
    把「螢幕擷取畫面」另歸一類，最後寫一份整理報告.md。

WHAT TO NOTICE

觀察重點

① 它怎麼做事

讀檔 → 提出計畫 → 請你確認 → 動手 → 回報。

② 確認機制

體會 Turbo Mode 開／關時，「要不要你逐次允許」的差別。

③ 對照報告

打開 整理報告.md，看它搬了哪些檔。

④ 不怕做錯

跑錯可以叫它還原或重做——這是練習。
